# 小红书组图风格库

每种风格四要素：适用内容、三变量（文案风格 / 背景 / 元素）、封面版提示词骨架、副图版提示词骨架。

占位符约定：
- `{主文案}` 封面主标题（≤12 字）；`{高亮词}` 主文案中要强调的词；`{副文案}` 封面辅助短句（≤20 字，可空）；为空时，删除骨架中含 {副文案} 的整个子句（连同便签纸 / 对话气泡 / 标签胶囊等载体描述）
- `{要点标题}`（≤10 字）/ `{要点内容}`（1-3 条短句）：副图要点；{要点内容} 多条时各条以①②③序号连接后填入
- `{目录预览}`：封面上的内容预览清单，填各张副图的 {要点标题} 拼接，每条 ≤8 字
- `{背景色}` / `{高亮色}`：确认卡阶段根据内容主题定具体色
- 配色口诀：**1 主色 + 1 辅助色 + 1 点缀色**；垂类取色指引——美食类橙红 / 干货类蓝绿 / 情感类粉紫，确认卡阶段定 `{背景色}` / `{高亮色}` 时按此映射
- 负面清单（已淘汰风向，组装提示词时规避）：**模板化套用感、过度滤镜网红感**；默认追加一句"画面避免模板化套用感和过度滤镜的网红感"，置于统一尾句之前

所有提示词组装后默认追加一句：**"竖版 3:4 构图，高清，所有中文文字必须准确、清晰、无错别字。"**
副图版提示词骨架配合 `--image-input <封面assetId>` 使用，提示词里写"与参考图保持一致"即指封面。

## 1. 大字报风

- 适用：知识 / 职场向干货（观点输出、避坑、攻略、痛点直给的悬念式标题）
- 文案风格：素底上超大粗黑体或粗手写大字怼脸排满版心，悬念句或痛点直给，关键字换色、描边或下划线
- 背景：纯白 / 浅灰 / 米色素底，偶用单一高饱和色块
- 元素：荧光色块高亮、手绘圆圈圈注、emoji、小箭头，装饰极少、以字为主

封面版骨架：
> 小红书大字报风封面图。{背景色}素色背景，超大号粗黑体中文标题"{主文案}"顶天立地铺满版面，关键词"{高亮词}"用{高亮色}荧光色块高亮并加手绘圆圈圈注，标题下方一行小字"{副文案}"，点缀 1-2 个 emoji 和手绘小箭头，装饰极少、以字为主，扁平设计，构图饱满有视觉冲击力。

副图版骨架：
> 小红书大字报风内页图，与参考图保持完全一致的配色、字体和元素体系。顶部粗黑体中文小标题"{要点标题}"（字号明显小于封面主标题），下方分条排版：{要点内容}，每条前用同款{高亮色}色块序号标记，重点词用同款荧光色块划出，信息密度高于封面，版面仍保持素底干净。

## 2. 知识卡片风

- 适用：教程 / 方法论类干货（职场技能、拆书、工具教学、步骤拆解）
- 文案风格：清晰层级的无衬线字——超大标题 + 小号正文 + 列表，左对齐网格排版，关键词加色
- 背景：白色或浅色圆角大卡片，外层薄荷绿 / 米色 / 淡紫边框或底色
- 元素：扁平小图标、标签胶囊 chips、色块序号、进度条等 UI 组件、底部作者信息条、页码角标
- 子风格（确认卡可选用调整配色与质感）：商务专业（大地色+衬线）／科普海报（亮蓝橙+扁平图标）／科技未来（深底荧光青紫）／数据图表（渐变蓝图表）／简洁插画（手绘涂鸦+暖纸底）／瑞士国际主义（粗无衬线+严格网格+蓝橙）；选用子风格时，以其配色质感替换骨架中的 {背景色} 与"大厂 UI 信息图风格"措辞

封面版骨架：
> 小红书知识卡片风封面图。{背景色}边框底色上一张白色圆角大卡片，卡片顶部超大号加粗无衬线中文标题"{主文案}"左对齐，关键词"{高亮词}"用{高亮色}标注，卡片中部左对齐逐行列出：{目录预览}，每行配一个扁平小图标，底部一枚标签胶囊"{副文案}"，大厂 UI 信息图风格，层级清晰、干净专业。

副图版骨架：
> 小红书知识卡片风内页图，与参考图保持完全一致的卡片样式、配色和字体体系。白色圆角卡片顶部{高亮色}色块序号 + 加粗无衬线小标题"{要点标题}"，卡片主体左对齐分条列出：{要点内容}，重点词用同款{高亮色}标注，配 1-2 个扁平小图标，右下角页码角标，信息密度高于封面、层级清晰。

## 3. 手帐拼贴风

- 适用：生活记录 / vlog 类图文（好物分享、旅行、日常记录）
- 文案风格：居中大标题压在拼图上，手写体或圆体，字数少
- 背景：2-4 张同色调实拍照片拼成网格，或奶白 / 牛皮纸纯色底 + 多物件抠图矩阵
- 元素：白边贴纸、撕纸胶带边、抠图白描边、便签纸、手绘箭头小图标

封面版骨架：
> 小红书手帐拼贴风封面图。2-4 张同色调（莫兰迪色系）生活实拍照片拼成网格，照片间留白色贴纸边框，边缘做撕纸和胶带固定效果，画面中央手写体中文大标题"{主文案}"压在拼图上，角落散落小贴纸和手绘箭头，旁边便签纸上手写小字"{副文案}"，温暖随性的拼贴质感。

副图版骨架：
> 小红书手帐拼贴风内页图，与参考图保持完全一致的照片色调、贴纸胶带和手写字体体系。顶部手写体小标题"{要点标题}"写在便签纸上并用胶带贴住，下方 1-2 张同色调实拍小图配抠图白描边，旁边手帐式排版列出：{要点内容}，配手绘箭头和小贴纸点缀，信息量多于封面但保持随性拼贴感。

## 4. 杂志编辑风

- 适用：文艺 / 审美向内容（摄影、人文、氛围感生活方式、穿搭家居）
- 文案风格：衬线体 / 书法体小字号，竖排 + 横排混合，中英文混排，刊头 / 日期 / 栏目小字营造刊物感
- 背景：满版氛围摄影（自然 / 人文题材），暗调或低饱和
- 元素：细线框、极细分割线、页码标记、大量留白，零卡通装饰

封面版骨架：
> 小红书杂志编辑风封面图。满版低饱和暗调氛围摄影打底（自然或人文题材），上方小号英文刊头与日期，中央偏左衬线体中文标题"{主文案}"竖排排布，旁边一行横排英文小字呼应，细线框内一行小字"{副文案}"，摄影画面本身构图疏朗、留出大面积负空间承载文字，零卡通装饰，如高级文艺杂志封面，克制有氛围感。

副图版骨架：
> 小红书杂志编辑风内页图，与参考图保持完全一致的摄影色调、衬线字体和细线框体系。顶部极细分割线下衬线体小标题"{要点标题}"，正文区竖横混排优雅列出：{要点内容}，右下角小页码标记，信息密度高于封面但仍保持大量留白与编辑感。

## 5. 奶油 ins 风

- 适用：温柔治愈系 / 生活情感类（母婴、美食、咖啡、日常感悟）
- 文案风格：小号细字或可爱手写体短句，不抢画面，常加简单白色描边
- 背景：奶油色 / 低饱和暖调实拍（生活场景、户外柔光），轻微过曝的奶油感
- 元素：小贴纸、emoji、手绘爱心星星，装饰轻量

封面版骨架：
> 小红书奶油 ins 风封面图。{背景色}奶油色低饱和暖调生活实拍场景打底，柔和自然光、轻微过曝的奶油感，画面上方可爱手写体中文标题"{主文案}"加简单白色描边，下方一行小字"{副文案}"，点缀 1-2 个小贴纸和手绘爱心星星，装饰轻量不抢画面，整体温柔治愈。

副图版骨架：
> 小红书奶油 ins 风内页图，与参考图保持完全一致的奶油色调、手写字体和贴纸体系。顶部手写体小标题"{要点标题}"加白色描边，画面留白处柔和排版列出：{要点内容}，配同款小贴纸和手绘星星点缀，信息量多于封面，保持柔光奶油质感和治愈氛围。

## 6. 多巴胺撞色风

- 适用：情绪共鸣 / 年轻向内容（吐槽、共鸣金句、热点话题、潮流种草安利）
- 文案风格：超大圆体或粗黑体，逐行换色（红蓝 / 橙绿撞色），口语化情绪句 + 感叹号
- 背景：高饱和纯色或大色块拼接（蓝橙 / 紫黄 / 粉绿）；本风格 {背景色} 填撞色组合（如"蓝橙"）
- 元素：大号 emoji / 卡通表情包（约占画面三分之一）、对话气泡、爆炸贴纸

封面版骨架：
> 小红书多巴胺撞色风封面图。{背景色}高饱和大色块拼接背景，中央超大号圆体中文标题"{主文案}"逐行换撞色排布，关键词"{高亮词}"放进{高亮色}爆炸贴纸框，旁边一个约占画面三分之一的大号卡通表情包呼应情绪，对话气泡内小字"{副文案}"，颜色对比强烈，信息流里抢眼，活力四射。

副图版骨架：
> 小红书多巴胺撞色风内页图，与参考图保持完全一致的撞色配色、圆体字和表情包元素体系。顶部色块上粗体小标题"{要点标题}"，下方错位活泼地分条排布：{要点内容}，重点句配小号同款表情包或对话气泡，保持高饱和撞色，信息密度高于封面。

## 7. 极简备忘录风

- 适用：干货清单 / 合集类（工具清单、书单、习惯打卡、纯文字干货罗列）
- 文案风格：手写体 / 备忘录字体的干货清单，逐行列点，数字编号，关键词荧光笔划重点
- 背景：白底或仿纸张纹理（横线本 / 格纹），轻拟物
- 元素：荧光笔笔触、勾选框、回形针 / 胶带小装饰，整体极简

封面版骨架：
> 小红书极简备忘录风封面图。白底仿横线笔记本纸张纹理背景，顶部手写体中文大标题"{主文案}"，关键词"{高亮词}"用{高亮色}荧光笔笔触划重点，下方手写体带数字编号逐行列出：{目录预览}，每条前一个小勾选框，底部一行手写小字"{副文案}"，角落一枚回形针或一段胶带小装饰，像一页认真记录的备忘录，极简干净。

副图版骨架：
> 小红书极简备忘录风内页图，与参考图保持完全一致的纸张纹理、手写字体和荧光笔颜色体系。顶部手写体小标题"{要点标题}"配勾选框，纸面逐行列点写出：{要点内容}，带数字编号，关键词用同款{高亮色}荧光笔划重点，信息密度高于封面，保持备忘录质感。

## 8. 真人实拍贴字风

- 适用：人物照 / 探店照 / 日常随拍类内容（情绪表达、个人 IP、探店记录）；用户已有真人或实景素材时，可改用用户照片作 `--image-input` 参考图打底
- 文案风格：白色或亮色粗手写大字直接压在照片上，情绪化口语句，行距紧凑错落
- 背景：逼真生活感实拍照片（人物、风景、探店场景），保留真实感不过度修图
- 元素：人物外轮廓加轻薄白色撕纸描边抠图、白色手绘涂鸦（箭头 / 圈注 / 云朵 / 星星）与人物视线或手势互动

封面版骨架：
> 小红书真人实拍贴字风封面图。一张逼真生活感实拍照片打底（人物 / 风景 / 探店场景，自然光线，保留真实感不过度修图），人物外轮廓加一圈轻薄白色撕纸描边如抠图贴纸，满版白色粗手写体中文大标题"{主文案}"压在照片上、行距紧凑错落有节奏，关键词"{高亮词}"字号放大，加入与人物视线或手势互动的白色手绘涂鸦（箭头、圈注、云朵、星星），角落手写小字"{副文案}"，情绪感强。（照片无人物时：省略撕纸描边，手绘涂鸦改为指向场景主体物）

副图版骨架：
> 小红书真人实拍贴字风内页图，与参考图保持完全一致的照片色调、白色手写字和涂鸦风格体系。同一场景延续的生活感实拍照片打底，顶部白色粗手写体小标题"{要点标题}"，照片留白处手写排布：{要点内容}，配同款白色手绘箭头和圈注指向画面细节，信息量多于封面，保持真实生活感。
